# 新能源汽车的轻量级数据存储系统
随着新能源汽车产业的快速发展，生产车间内的数据量急剧增加，对数据的有效存储、实时监控和快速分析提出了更高要求。传统监控系统往往部署复杂、成本高昂，难以适应多变的车间环境。针对此问题，本文设计并实现了一套面向新能源汽车生产车间的轻量级数据存储与监控系统。该系统采用 B/S 架构，前端利用 HTML、CSS 和 JavaScript 技术，结合 Chart.js 库，实现了多车间（电池、焊接、总装、检测）模拟数据的实时可视化展示，包括关键指标的仪表盘图和历史数据趋势的折线图。后端基于 Node.js 和 Express 框架构建 API 服务，选用轻量级数据库 SQLite 进行数据存储，并对存入数据库中的数据进行数据存储优化，有效降低了部署和维护成本。
